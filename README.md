# Black Sheep Dev Test Submission

A responsive two-section layout (hero + service cards) built from the provided Figma design.

## Design Implementation
- **Figma Translation:** Extracted layout requirements, typography, and color palettes directly from the Figma design file.
- **Layout & Spacing:** Matched component dimensions, padding, and card spacing based on the design specs.
- **Hero Section:** Implemented a full-width banner with a CSS linear-gradient overlay to ensure text readability and match the design's aesthetic.
- **Responsive Breakpoints:** Built mobile and tablet views using CSS media queries, ensuring elements stack and scale correctly.

## Technical Notes
- Built with HTML5 and Vanilla CSS (no frameworks).
- Uses CSS Flexbox for the card layout.
- Basic accessibility included (alt text, ARIA labels, semantic tags).
- CTA links are `href="#"` placeholders pending real routes.
